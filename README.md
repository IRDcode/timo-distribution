## نصب

1. فایل `setup.exe` را اجرا کنید.
2. ویندوز ۱۰ یا ۱۱، نسخه‌ی ۶۴ بیتی — پیش‌نیاز دیگری لازم نیست.
3. نصب نسخه‌ی تازه روی نسخه‌ی قبلی، همان نصب را به‌روز می‌کند؛ تنظیمات و رویدادها دست‌نخورده می‌مانند.
